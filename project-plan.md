# ArchiveFuse — Project Plan

1. **Truth scaffold** — docs, environment, package/tooling and no-backend boundary.
2. **Deterministic contract** — storage, authorization, immutable records, bounds, pagination and cutoff.
3. **Semantic memory** — normalized 384d embeddings, bounded filtered KNN and candidate preview.
4. **Consensus resolution** — source digest verification, hostile-evidence guard, structured relations, independent validators and deterministic settlement.
5. **Correction provenance** — versioned challenge/keep/detach path without erasing old receipts.
6. **Live web client** — injected wallet, chain gate, typed reads/writes, FINALIZED + GenVM verification.
7. **Distinct frontend** — collection shelves, accession cards, light table, dossiers, receipts, lineage, source viewer and timeline.
8. **Adversarial verification** — forged/weak semantic outcomes, unavailable reads, cutoff, no direct similarity merge, no hidden backend/mocks.
9. **StudioNet proof** — deploy, verify schema/source, exercise real lifecycle and record only real evidence.
10. **Release** — Vercel-ready frontend, accessibility/responsive pass and honest deployment metadata.
